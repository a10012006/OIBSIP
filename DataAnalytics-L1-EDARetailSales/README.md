# Retail Sales EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on retail sales data to identify sales trends, customer behaviour patterns, product performance, and relationships between numerical variables.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data inspection and quality check
- Descriptive statistics
- Monthly and quarterly sales trends
- Customer age and gender analysis
- Product category analysis
- Correlation analysis
- Additional visualisation
- Business insights and recommendations
